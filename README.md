## Project description
A reproducible Python analytics project using Tableau's educational Sample Superstore retail dataset. The notebook validates and cleans records, calculates sales and profit KPIs, compares categories and regions, charts monthly trends, analyses discount bands, and exports tables and figures.

## Dataset
- Primary source: [Tableau Public Sample Data](https://public.tableau.com/app/learn/sample-data) — find **Superstore Sales**.
- Alternative: [Kaggle – Superstore Dataset](https://www.kaggle.com/datasets/vivek468/superstore-dataset-final).

Download/export the **Orders** data as CSV and save it beside the notebook as `Sample - Superstore.csv`. If supplied as Excel, export only the Orders sheet. Supported alternate names are documented in the notebook. The sample data is fictional/educational; copies may differ, so report only values generated by your own run.

## Setup and run
Use Python 3.10 or newer.

1. Download the dataset above and place the Orders CSV beside the notebook.
2. Open a terminal in this folder and create a virtual environment (recommended):
   - Windows: `python -m venv .venv` then `.venv\Scripts\activate`
   - macOS/Linux: `python3 -m venv .venv` then `source .venv/bin/activate`
3. Install dependencies: `python -m pip install -r requirements.txt`
4. Start Jupyter: `jupyter notebook`
5. Open `PrathameshJadhav_SalesDataAnalysis.ipynb` and select **Run All**.

The notebook creates an `outputs/` folder with KPI summaries, segment tables, and PNG charts.

## Questions explored
- What are total sales, profit, profit margin, order count, and quantity?
- Which categories and regions contribute the most sales/profit?
- Which sub-categories have low or negative profit?
- How do sales and profit change by month?
- How does profit margin vary by discount band?

## Limitations and integrity
The dataset is fictional and does not represent a real company. Group relationships do not prove causation. The optional moving-average baseline is illustrative, not a validated AI forecasting model. Run the notebook and update the report using actual outputs; do not claim results that have not been reproduced.
