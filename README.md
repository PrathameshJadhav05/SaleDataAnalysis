# SaleDataAnalysis
Sales Data Analysis using Python, Pandas, NumPy, and Matplotlib. This project explores the Sample Superstore retail dataset through data cleaning, exploratory data analysis (EDA), KPI calculations, data visualization, and business insights to understand sales, profit, regional performance, and discount trends.

## 📌 Project Overview

This project analyzes retail sales data to understand business performance and identify useful insights from sales, profit, orders, product categories, regions, and discount trends.

The project uses Python-based data analytics techniques to clean and validate data, calculate key performance indicators (KPIs), perform exploratory data analysis (EDA), and create visualizations that support data-driven decision-making.

## 🎯 Objectives

- Clean and validate the retail dataset.
- Calculate key business metrics, including total sales, profit, profit margin, and order count.
- Analyze sales and profit across product categories and regions.
- Explore monthly sales trends.
- Examine the relationship between discount levels and profitability.
- Present findings through charts and summary tables.

## 🛠️ Technologies Used

- **Pandas** — Data manipulation and analysis.

## 🚀 How to Run the Project

1. Clone this repository:

   ```bash
   git clone YOUR_REPOSITORY_URL
   ```

2. Open the project folder:

   ```bash
   cd SalesDataAnalysis
   ```

3. Install the required libraries:

   ```bash
   pip install pandas numpy matplotlib jupyter
   ```

4. Download the Tableau Sample Superstore dataset from the [Tableau Sample Data page](https://public.tableau.com/app/learn/sample-data).

5. Place the dataset in the project folder using one of the filenames supported by the notebook, or update the dataset path in the code.

6. Launch Jupyter Notebook:

   ```bash
   jupyter notebook
   ```

7. Open the notebook and run the cells from top to bottom.
